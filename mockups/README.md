# Reference Design Mockups

This directory contains the original static Stitch HTML mockups created during the initial visual design phase of **KEA-Verify**.

These files serve as reference visual benchmarks:
- `index.html` → Redirects to `login.html`
- `login.html` → Invigilator authentication mockup
- `dashboard.html` → Exam centre dashboard & candidate stats mockup
- `qr_scan.html` → QR scanning reticle & guidance mockup
- `manual_verification.html` → Candidate photo review & manual override mockup
- `records_history.html` → Audit history log mockup
- `verification_complete.html` → Verification success state mockup

> **Note**: The live production application is built with **React Native / Expo** inside `src/app/`. These HTML files are preserved strictly for visual design reference.
